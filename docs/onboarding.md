# Job Agent 首次建档

本机网页提供“下载资料包模板 ZIP → 填写根目录的 `个人信息表.xlsx` → 整理证明文件 → 一次上传 ZIP → 查看解析内容 → 核对并保存”流程。个人信息表固定了基本信息、教育、工作实习、项目、论文、证书和奖项栏位；上传后自动填入网页对应板块。语言证书及明确标注为项目、论文或奖项的证明文件也会补充到相应的待核对表格；同名记录不重复添加，缺少证据的字段保留空白。模板另含 `使用说明.txt` 和以下文件夹：

| 文件夹 | 放入的材料 |
| --- | --- |
| `01_简历` | 唯一一份简历，必填 |
| `02_教育与成绩` | 学历学位、在读证明、学籍验证、成绩单 |
| `03_工作与实习` | 工作或实习证明 |
| `04_语言与资格证书` | 雅思、四六级、职业资格 |
| `05_项目与成果` | 项目材料、作品集、论文、专利、奖项 |
| `06_证件与签证` | 按需提供；保存前须单独确认 |

个人信息表须保持工作表和表头名称不变，姓名必填；最多每类 30 行。文件名建议包含材料名称、日期、成绩等，例如 `雅思_2026-03_6.5.pdf`、`论文_题目_第一作者.pdf`。上传后优先按文件夹分类，未按模板整理时才尝试用文件名分类。无法归类或格式不支持的文件会显示警告并跳过。每份文件最大 15 MB，简历最大 10 MB；ZIP 最大 50 MB。支持 JPG/PNG、TXT、PDF、DOC/DOCX；XLSX 证明可保存，但暂不自动解析。图片与扫描 PDF 使用本机 macOS Vision OCR。识别结果可核对修改，不明确的信息留空。

工作/实习、项目、论文和奖项表格可选择 AI 润色。用户须先在设置中保存模型 API Key，再逐行打开对话框、给出修改要求、重新生成并主动应用。润色不得捏造事实。API Key 仅存本机 `data/private/llm-settings.json`，文件权限 0600；调用模型时该行内容会发送给所选服务商。

确认后个人信息表及其他原文件存于 Git 忽略的 `data/private/intake/`，档案存于 `data/profile.json`。上传证明不等于同意将其发给招聘网站。后续使用者粘贴职位 URL，仍需人工处理不确定字段并停在最终提交前。

当前是单机内测，不提供多用户隔离或云端同步。银行卡、户口本、社保记录和无关资料不应放进标准资料包。
