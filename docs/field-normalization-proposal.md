# Job Agent 跨站字段归一与选项匹配表

此表定义候选值及安全边界。实际填写时，先读取目标网站的真实选项；没有可验证的等价项就留空并提示用户。不得根据简历推断未提供的事实。已实现工作身份、语言类型、到岗时间的明确同义词，以及地点名称的保守归一；其他类别仍保持精确匹配或人工核对。

## 路由顺序建议

1. 先确定字段语义与作用域：当前／期望、学历／学位、实习／正式、籍贯／所在地／意向地。
2. 将档案值归一为结构化值，同时保留原文和来源。
3. 读取网站当前可见选项；优先精确匹配，其次使用本表已确认的同义词。
4. 对范围、日期、分类树做专门比较；没有唯一且安全的结果时留空并列出候选。
5. 选中后读取页面实际值验证；未生效则标记失败，不计入已填写。

## 本次国科微实测结论

- 档案“应届生”与网站“应届毕业生”需要同义映射；网站另有“在读学生”，不能混用。
- 籍贯与出生日期未填的原因是网站自定义控件结构与当前适配器不符；属于控件操作问题，不靠同义词表解决。
- 现从事行业、职业、城市、薪资等下拉项需要分别核对网站真实选项，不应对所有字段套同一个字符串匹配器。
